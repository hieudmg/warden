# React and shadcn/ui Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Warden's vanilla management UI with a self-contained, light-theme React/shadcn application using module tabs, record-backed relationship controls, and a responsive three-pane projects/reports view.

**Architecture:** A `web/` React/TypeScript project builds with Vite into ignored `internal/web/dist/`; Go embeds that generated directory and serves its recursive hashed assets. Typed API functions and focused feature components preserve existing server contracts, including null secret updates and exceptional stored relationship IDs.

**Tech Stack:** React 19, TypeScript, Vite 8, Tailwind CSS 4, shadcn/ui with Radix primitives, Vitest 4, React Testing Library, Go `embed`/`io/fs`, existing Go HTTP API.

**Spec:** `docs/superpowers/specs/2026-08-24-react-shadcn-frontend-design.md`

## Global Constraints

- Keep existing `/api/v1/ssh-connections`, `/api/v1/db-connections`, `/api/v1/projects`, `/api/v1/reports`, dependent, and transport routes plus their JSON payloads unchanged.
- Default and only theme is light; do not add dark-mode state or a theme switcher.
- Runtime frontend must contain no CDN, external font, external script, or external stylesheet dependency.
- Generated `internal/web/dist/` is ignored and never committed.
- Any documented command compiling `internal/web` must build frontend first.
- Blank SSH/DB secret inputs serialize as JSON `null` or omission, never `""`.
- Existing exceptional jump entries—missing, duplicate, self, cyclic, zero, and negative IDs—survive unrelated edits in their original order.
- Add controls cannot create new self-references or duplicate jump entries.
- Projects & Reports uses one column below `64rem` and three columns at or above `64rem`; DOM order is Projects, Reports, Report content.
- Preserve management-only security boundary: no credential reveal, terminal, SQL execution, remote execution, or connection test.
- Do not modify unrelated untracked `.cmdlog/` or `Master key path [/` paths.

- [ ] **Step 4: Implement minimal manifest verifier needed by Vite build**

Export `verifyDist(root)` and CLI handling. Walk manifest `file`, `css`, `assets`, `imports`, and `dynamicImports`; verify referenced keys and emitted files exist. Parse HTML `src`/`href` and CSS `url(...)`; allow root-relative, relative, and `data:` references; reject `http:`, `https:`, and protocol-relative `//` values.

```js
export async function verifyDist(root) {
  const manifestPath = path.join(root, ".vite", "manifest.json")
  const manifest = JSON.parse(await readFile(manifestPath, "utf8"))
  const emitted = new Set()
  for (const [key, entry] of Object.entries(manifest)) {
    if (entry.file) emitted.add(entry.file)
    for (const file of entry.css ?? []) emitted.add(file)
    for (const file of entry.assets ?? []) emitted.add(file)
    for (const imported of [...(entry.imports ?? []), ...(entry.dynamicImports ?? [])]) {
      if (!manifest[imported]) throw new Error(`manifest import missing: ${key} -> ${imported}`)
    }
  }
  for (const file of emitted) await access(path.join(root, file))
  await rejectExternalReferences(root)
}
```

Use a monotonically increasing request ID and `AbortController`:

```ts
export function useListResource<T>(loader: (signal: AbortSignal) => Promise<T[]>): ListResource<T> {
  const [state, setState] = useState({ data: [] as T[], loading: true, error: null as Error | null })
  const requestID = useRef(0)
  const controller = useRef<AbortController | null>(null)
  const reload = useCallback(async () => {
    const id = ++requestID.current
    controller.current?.abort()
    const next = new AbortController()
    controller.current = next
    setState(current => ({ ...current, loading: true, error: null }))
    try {
      const data = await loader(next.signal)
      if (id === requestID.current) setState({ data, loading: false, error: null })
    } catch (error) {
      if (!next.signal.aborted && id === requestID.current) {
        setState(current => ({ ...current, loading: false, error: error as Error }))
      }
    }
  }, [loader])
  useEffect(() => { void reload(); return () => controller.current?.abort() }, [reload])
  return { ...state, reload }
}
```

```ts
  if (from === to || from < 0 || to < 0 || from >= ids.length || to >= ids.length) return [...ids]
  const next = [...ids]
  const [item] = next.splice(from, 1)
  next.splice(to, 0, item)
  return next
}

export function jumpCandidates(profiles: readonly SSHConnection[], selectedIDs: readonly number[], editingID?: number) {
  const unavailable = new Set(selectedIDs)
  if (editingID !== undefined) unavailable.add(editingID)
  return profiles.filter(profile => !unavailable.has(profile.id))
}
```

`parseJumpRoute` accepts only arrays where every value satisfies `Number.isInteger`; it does not reject zero, negative, duplicate, self, or graph-cyclic values.
